# Database Migrations

This directory contains SQL migration scripts for setting up the model performance tracking database schema.

## Tables

1. **models** - Stores ML model configurations and metadata
2. **trades** - Individual trade records generated by models  
3. **performance_metrics** - Aggregated performance data for analysis
4. **model_updates** - Tracks model changes and retraining events

## Running Migrations

### Option 1: Using Vercel CLI

```bash
# Install Vercel CLI if not already installed
npm i -g vercel

# Link your project
vercel link

# Pull environment variables
vercel env pull .env.local

# Run migrations using psql
psql $POSTGRES_URL -f db/migrations/001_create_models_table.sql
psql $POSTGRES_URL -f db/migrations/002_create_trades_table.sql
psql $POSTGRES_URL -f db/migrations/003_create_performance_metrics_table.sql
psql $POSTGRES_URL -f db/migrations/004_create_model_updates_table.sql
psql $POSTGRES_URL -f db/migrations/005_create_indexes_and_views.sql
```

### Option 2: Using Vercel Dashboard

1. Go to your Vercel project dashboard
2. Navigate to Storage → Your Postgres Database
3. Click on "Query" tab
4. Copy and paste each migration file content in order

### Option 3: Programmatic Migration

Create an API route to run migrations:

```typescript
// app/api/db/migrate/route.ts
import { sql } from '@/lib/db';

export async function POST() {
  // Run your migrations here
  // Only use in development!
}
```

## Migration Order

Migrations must be run in numerical order:

1. `001_create_models_table.sql` - Base models table with enums
2. `002_create_trades_table.sql` - Trades with FK to models
3. `003_create_performance_metrics_table.sql` - Performance metrics
4. `004_create_model_updates_table.sql` - Model update history
5. `005_create_indexes_and_views.sql` - Additional indexes and views


## Rolling Back

To drop all tables and start fresh:

```sql
DROP VIEW IF EXISTS v_model_update_impact;
DROP VIEW IF EXISTS v_daily_trade_performance;
DROP VIEW IF EXISTS v_model_summary;
DROP VIEW IF EXISTS v_latest_model_performance;

DROP TABLE IF EXISTS model_updates;
DROP TABLE IF EXISTS performance_metrics;
DROP TABLE IF EXISTS trades;
DROP TABLE IF EXISTS models;

DROP TYPE IF EXISTS update_type;
DROP TYPE IF EXISTS trade_status;
DROP TYPE IF EXISTS trade_direction;
DROP TYPE IF EXISTS model_status;

DROP FUNCTION IF EXISTS update_updated_at_column();
DROP FUNCTION IF EXISTS calculate_trade_pnl();
```
